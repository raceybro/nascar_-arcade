# NASCAR ARCADE
A static, mobile-friendly fan archive with an original browser-playable top-down stock-car mini-game.

## Run locally
Open `index.html` in a modern browser. No build tools or server are required.

## Publish publicly with GitHub Pages
1. Create a new public GitHub repository (for example, `nascar-arcade`).
2. Upload the contents of this folder to the repository root (not the folder itself).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish. The public URL appears in the Pages settings.

## Important scope and rights
- The included archive is a starter index, not an exhaustive list of every NASCAR game. Contributions can be added to `games.js`.
- Commercial game ROMs, ISOs, executables, BIOS files, and copyrighted assets are not included or redistributed.
- The built-in demo is original code and is not a port of a licensed NASCAR title.
- `playUrl` is optional metadata. Only add a URL for a browser game you own, have permission to host, or are linking to through an authorized provider.
- NASCAR and game titles/logos are trademarks of their respective owners. This is an unofficial fan project.
